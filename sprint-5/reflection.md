# Reflection

This sprint helped me understand how Apex communicates with Salesforce data.

Earlier, my application already had business validation rules. In this sprint, I learned how to retrieve the information required for those rules using SOQL and how to save changes using DML.

I also understood why separating data access from business logic makes the code easier to maintain.

The most important thing I learned is that software should first retrieve the required information, then validate the business rules, and only after that change the data.

I also gained confidence by testing the complete application process directly through the Placement Management App.

### My Key Takeaway

> **First retrieve the information, then make the decision, and finally change the data.**

Sprint 5 helped me understand how SOQL, DML, Apex services, and triggers work together in a real Salesforce application.
