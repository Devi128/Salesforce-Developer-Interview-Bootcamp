# Day 2 Reflection – Apex Triggers & Governor Limits

## Reflection

Today I learned about Apex Triggers, Governor Limits, and how Salesforce handles automation using code. I understood how to convert business requirements into technical solutions and decide whether to use a Validation Rule, Flow, or Trigger.

I practiced creating triggers and learned the importance of choosing the correct trigger event based on the requirement. I also learned why Trigger Handler Classes are used to keep the code clean, organized, and reusable.

One of the important concepts I learned today was bulkification. I understood that Salesforce triggers should not be written only for a single record because Salesforce processes multiple records at the same time. I learned how to avoid common issues like SOQL queries inside loops and how to use collections such as Lists, Sets, and Maps.

While working on the tasks, I faced challenges in understanding trigger execution flow, writing optimized queries, and debugging errors. By practicing different scenarios and analyzing the errors, I improved my understanding of Apex development.

Overall, today's session helped me understand how real-world Salesforce developers design automation solutions. I gained more confidence in writing triggers, handling governor limits, and following Salesforce development best practices.

## Key Learning

- Learned the difference between Validation Rules, Flows, and Apex Triggers.
- Understood trigger events and execution flow.
- Learned the importance of bulkified code.
- Improved knowledge of SOQL and DML operations.
- Understood the purpose of Trigger Handler Classes.
- Learned how to debug and test Apex Trigger logic.
